# Электропокер

Мобильная казино-аркада на семи картах. Игрок получает семь карт, выбирает карты для перетусовки, а игра определяет лучшую покерную комбинацию из пяти карт.

**[Играть в браузере](https://vyacheslav666-cpu.github.io/electric_poker_yanasolyah/)**

Проект написан на чистых HTML, CSS и JavaScript: без фреймворков, сборщика, внешних библиотек и серверной части.

Статус качества: игровой движок, расчёт вероятностей, сохранение и Pages-ссылки покрыты автоматическими тестами на встроенном Node.js test runner.

## Возможности

- семь карт и одна перетусовка выбранных карт;
- подсветка уже собранной комбинации;
- отдельные анимации и цвета для разных комбинаций;
- управление ставкой: `−10`, `+10`, `÷2`, `×2`;
- история последних 30 партий;
- сохранение баланса и настроек в `localStorage`;
- звуковые эффекты и фоновый casino-jazz с отдельными переключателями;
- адаптивный полноэкранный интерфейс для смартфонов;
- справка с комбинациями и коэффициентами.

## Правила

1. Выберите ставку и нажмите **«Раздать 7 карт»**.
2. Нажмите на одну или несколько карт, которые хотите заменить.
3. Нажмите **«Перетусовать»**.
4. Засчитывается лучшая комбинация из пяти карт.

Все ставки и выигрыши используют только виртуальные очки.

## Запуск

Проект не требует сборки и зависимостей. Из-за нативных ES-модулей запускайте его через любой статический сервер:

```bash
python -m http.server 8000
```

После этого откройте <http://localhost:8000>.

### Проверка перед публикацией

Зависимости устанавливать не нужно. При наличии Node.js 20+ запустите:

```bash
npm test
```

Та же проверка автоматически выполняется перед каждым развёртыванием GitHub Pages.

## Архитектура

JavaScript использует нативные ES-модули без сборщика. Покерная математика не зависит от DOM, аудио получает только текущие настройки, а состояние интерфейса остаётся в `app.js`. Комментарии сосредоточены на алгоритмах и переходах состояния, а не повторяют очевидный код.

Подробное описание каталогов, зависимостей, состояния раунда, рендера, хранения данных и публикации находится в документе **[Архитектура проекта](docs/ARCHITECTURE.md)**.

### Где менять основные настройки

| Что изменить | Файл |
|---|---|
| коэффициенты, названия комбинаций, карты | `js/config.js` |
| правила определения комбинаций и подсказок | `js/poker.js` |
| ход раунда, кнопки, сообщения и DOM | `js/app.js` |
| casino-jazz и звуковые сигналы | `js/audio.js` |
| сохранение прогресса | `js/storage.js` |
| внешний вид, адаптивность и анимации | `styles.css` |
| разметка, справка и доступность | `index.html` |
| будущие изображения, иконки и аудиофайлы | `assets/` |

## Публикация

Workflow `.github/workflows/pages.yml` проверяет pull request, а после push в `main` запускает тесты, собирает минимальный runtime-артефакт и публикует его на GitHub Pages.

Новые возможности разрабатываются в отдельных ветках `agent/*`, чтобы музыку, темы и эффекты можно было проверять независимо перед объединением.
