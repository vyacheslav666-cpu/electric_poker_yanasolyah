# Assets

Каталог для статических ресурсов проекта.

```text
assets/
├── images/       # фоны и крупные растровые изображения
├── icons/        # SVG- и PNG-иконки интерфейса
├── textures/     # паттерны, шум и материалы игрового автомата
├── audio/
│   ├── music/    # фоновая музыка
│   └── sfx/      # звуковые эффекты
└── screenshots/  # изображения для README и страницы проекта
```

Сейчас оформление создаётся средствами CSS, а музыка и звуки — через Web Audio API в `js/audio.js`. Папки подготовлены для будущих файлов.
